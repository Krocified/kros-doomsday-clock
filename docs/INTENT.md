# Intent

A personal doomsday clock. One page, one number: how long until a fixed date.
Loads, starts ticking, shows days/hours/minutes/seconds until target. Nothing else.

## Why

Curiosity and dread in equal measure. Target date is fixed: 14 April 2027.

## Success

Open the file, see the four numbers counting down every second as a **split-flap display** —
the airport/Solari kind, flaps physically flipping over as each digit changes. Faithful enough
to the real machine to feel mechanical, not a generic CSS flip.

## Non-goals

No accounts, no backend, no notifications, no sharing.
